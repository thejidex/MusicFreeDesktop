# 手机歌单分享说明（v1.5）

## 同一局域网：扫码接收

1. 让电脑和手机接入同一路由器。电脑可用网线，手机可用 Wi-Fi；不需要登录账号或配置 WebDAV。
2. 在电脑的歌单菜单打开“发送到手机”，选择一个、多个或全部歌单。需要传本地歌曲文件时勾选“同时传输歌单中的本地音频”。
3. 点击生成二维码，在手机 MusicFree 的“从电脑接收”页面扫码。拒绝相机权限时，可粘贴电脑显示的完整连接地址。
4. 手机先显示歌单、歌曲、所需插件和本地音频，再确认新建或合并。重复接收同一来源歌单会按设备 ID 与歌单 ID 匹配；默认保留手机手动编辑及播放次数。

局域网连接使用短时随机会话，只提供本次选中的歌单与明确选中的本地文件。完成或取消后会结束会话。连接失败时检查两台设备是否处于同一局域网、电脑防火墙是否放行；也可以取消后导出文件。

本地音频传输上限为 8 GB，手机会检查剩余空间、文件大小和 SHA-256。未随传输带上的本地歌曲仍会进入歌单，并标记为“需要补充本地文件”。在线歌曲导入后由手机插件重新解析音源；缺少插件时可在预览中确认批量安装，安装失败不会丢弃歌单。

## 不在同一网络：文件导入

电脑在“设置 → 备份恢复”导出 JSON 歌单文件，再通过微信、QQ、网盘或 USB 传到手机。手机可从歌单交换页面选择文件，也可使用系统“打开方式”或“分享至 MusicFree”。这些入口会进入同一预览和导入流程。

**当前离线 JSON 文件不包含本地音频数据。** 对应条目保留，但手机会显示需要补充本地文件；如需传音频，请使用局域网扫码方式。文件导入支持旧版 JSON 备份。WebDAV 用于用户主动备份与获取歌单，不提供后台自动双向同步或删除传播。

## 预览中的选择

- 首次接收：创建歌单；同名但来源 ID 不同的歌单可并存。
- 再次接收同一来源歌单：默认合并，也可为所选歌单选择覆盖或创建副本；覆盖前保存恢复快照。
- 字段冲突：默认保留手机编辑；需要时可选择采用来源设备编辑。
- 播放次数：默认保留手机数据；可选采用来源设备的快照，不会重复累加。
- “我喜欢”：作为特殊歌单映射到手机的收藏歌单。

导入不复制桌面数据库、账号凭据、Cookie、过期播放地址或电脑绝对路径。
