# MusicFree v1.5 升级说明

## Windows 便携版

v1.5 使用独立目录 `MusicFree-v1.5`。运行 `MusicFree-v1.5-win-x64.exe` 会在 EXE 旁解压并启动；ZIP 用户需完整解压后运行 `MusicFree.exe`。

若要沿用 v1.4 的便携数据：

1. 退出 v1.4 和 v1.5。
2. 备份旧程序目录。
3. 将 v1.4 目录中的整个 `portable` 文件夹复制到 `MusicFree-v1.5`，替换目标目录。
4. 启动 v1.5，检查歌单、插件、主题和设置。

不要在程序运行时复制数据。下载的 EXE/ZIP 是空白程序包，不含用户歌单、账号、插件配置或便携数据。保留整个版本目录，因为 `portable` 保存用户数据。

## Android

v1.4 的持久签名密钥已在本机找回，v1.5 arm64 APK 使用相同证书，应用标识不变，版本代码由 10400 升至 10500。覆盖安装及歌单、插件配置和编辑信息保留尚未在真机验证；升级前建议使用旧版备份功能保存数据。请勿用旧 Debug APK 尝试覆盖。

## 校验 Windows 文件

使用 SHA-256 工具核对 `SHA256SUMS-v1.5.txt` 中对应文件的摘要。详细构建、自动化检查和设备验证边界见[验证报告](./验证报告-v1.5.md)。
