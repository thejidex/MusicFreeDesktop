## 歌单交换验收边界

- 格式层包含独立版本、来源设备/歌单身份、歌曲原始平台与 ID、过滤后的插件业务字段、编辑标记、插件来源、播放次数和附件校验字段；不把账号凭据、Cookie、过期播放地址或桌面绝对路径写入交换数据。
- 同一来源的二次接收按来源 ID 匹配；在线曲目按平台与歌曲 ID 去重；默认保留手机字段修改和统计快照。“我喜欢”映射为目标端收藏歌单。
- 桌面局域网传输采用短时随机令牌，仅暴露所选歌单及明确勾选的附件；手机提供扫码与粘贴地址，并可取消接收。
- 手机文件选择、系统共享内容和扫码连接进入同一解析/预览管线。导入插件失败不会与歌单提交绑定为一个不可恢复步骤。
- **文件导出与 LAN 附件能力不对称：** 当前离线 JSON 没有封装本地音频；不能据此声称“离线分享包携带音频”已完成。
- 本机 HTTP 测试已传输 1,000 首歌曲的清单并检查附件取消/重试；手机端 1,000 首歌曲导入、重复导入及失败恢复使用内存适配器回归。尚未完成电脑与真实 Android 设备间的端到端传输，以及千首歌单、断网、损坏输入和事务回滚的全链路设备测试。

## Android 16 KB 与升级兼容

- React Native/Hermes 及相关 Android 工具链已升级；Track Player 和 FlashList 对 RN 0.81 的局部补丁带版本和源码片段校验，Fresco GIF 原生库同步到兼容版本。
- v1.5 arm64 签名 APK 的 ELF 与 ZIP 对齐检查通过；这只能证明二进制满足静态对齐检查要求。
- 本机创建了 4 KB/16 KB AVD 配置，但 `emulator -accel-check` 未通过：Windows Hyper-V/WHPX 加速不可用；无已连接设备。4 KB 与 16 KB 软件模拟器尝试启动后 ADB 均处于离线状态，因此模拟器运行和真机运行均未验证。
- 已在本机找回 v1.4 持久签名配置，v1.5 APK 的公开证书与旧 APK 一致。旧 APK 覆盖升级后歌单、插件设置和手动编辑保留尚未验证。不要将旧 Debug APK 当作升级包。

## 尚未通过的发布门槛

1. 在设备上验证 v1.4 到 v1.5 的覆盖升级及用户数据保留。
2. 在可启动的 4 KB 与 16 KB Android 环境，至少一台真机上验证安装、后台播放、蓝牙、下载、离线、本地文件和合集功能。
3. 执行真实电脑—手机扫码传输，覆盖缺插件、本地音频、断网、取消、重试、损坏文件和再次导入；另测千首歌单。
4. 完成 11 款主题设备布局/资源检查，并审计常用桌面插件的移动端兼容原因。
5. 为离线文件导出实现和验证可携带本地音频的安全分享包；目前只有局域网传输支持附件。

本报告按已执行的自动化、APK 静态检查和当前设备环境记录结果；没有通过的项目保持为未验证，不以 APK 构建成功替代功能验收。
