# Mobile source provenance

This mobile application is derived from [maotoumao/MusicFree](https://github.com/maotoumao/MusicFree), commit `d118b18b3d0c904400f7eea7bf99c0ceec6c1aee` (package version 0.6.2), retrieved on 2026-10-28.

Original author: 猫头猫 (maotoumao). The original AGPL-3.0 license is retained in `LICENSE`. Changes by thejidex are supplied under the same license. This is an independent fork, not an official upstream release.

The desktop Electron source remains in the repository root. The mobile application uses React Native and native Android/iOS audio services. There are no bundled audio-source plugins, accounts, playlists or portable profiles.
